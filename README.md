# Pitié Internationale: Bridging Worlds

onçois un site web moderne, élégant, responsive, multilingue (Français par défaut, Anglais prêt à être activé), optimisé SEO et conforme aux standards des grandes ONG internationales.

L'objectif est de renforcer la crédibilité de l'organisation, mobiliser les partenaires, attirer les bailleurs, recruter des volontaires et encourager les dons.
